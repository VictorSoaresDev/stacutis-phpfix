PHP2Shell scanner

CVE-2026-109618 and CVE-2026-109619 are critical PHP bugs disclosed on 21 October 2026. Both are scored CVSS v4.0 9.2. This page is a local checker for servers you administer.

Read the script before you run it. Do not pipe the download into a shell. The program is provided as-is. Take a backup before you answer yes to a change.

The button uses the public URL. The source link is the file in this tree, stacutis-php2shell.sh. A GitHub release URL is not hardcoded here. When you publish a release, point the button at that release and keep this checksum on stacutis.com as well.

What it is

Hitting memory_limit can abort PHP with longjmp() while request memory is only partly initialized (CVE-2026-109618). A fatal error at the wrong moment can leave global state pointing at freed memory for the next request on the same worker (CVE-2026-109619). The session upload-progress handler is on by default. On PHP 8.5, fatal-error backtraces are another confirmed path. Details and the disagreement between the PHP-FPM write-ups are in the README.

Upstream fixed releases: 8.5.12, 8.4.27, 8.3.36, and 8.2.35. PHP 8.1 and older have no upstream fixed release. Distro packages can still be patched; the scanner accepts that only when the local changelog names both CVEs.

What the tool does

  • Scans this host only. It does not spread, scan other machines, or send telemetry.
  • Reports each PHP SAPI as VULNERABLE, PATCHED, MITIGATED, or UNKNOWN. MITIGATED still means vulnerable.
  • Upgrades PHP with the system package manager, or writes temporary admin settings, only after you answer yes.
  • Backs up config under /var/backups/stacutis/ and can roll that backup back. A rollback does not downgrade packages.

A checksum matters only if you got it from a path you trust. This tree does not include a signing key. When the publisher signs a release, check that signature with a public key that arrived somewhere else.

gpg --verify stacutis-php2shell.sh.asc stacutis-php2shell.sh
minisign -Vm stacutis-php2shell.sh -p stacutis.pub

Publishers sign with gpg --detach-sign --armor or minisign -Sm. The commands and the source list are in the README.
